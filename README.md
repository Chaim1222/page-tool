# Page tool (המכלול)

גאדג'ט לעמוד הערך במכלול. הוא בודק מה קרה לערך בוויקיפדיה מאז שיובא (שינוי שם, הפניה, מחיקה ועוד) ומציע את הפעולה המתאימה: העברה, הפיכה להפניה, בקשה ממפעילים. לצד זה: מחוון גודל מול ויקיפדיה, "מאז הייבוא", ייבוא הפניות חסרות, תיקון קישורים אחרי העברה, והבדלים ו"פתיח".

## הקבצים

כל הקוד שמודבק לאתר נמצא בתיקייה `site/`. שמות הדפים באתר לא השתנו, והם מופיעים בטבלה. כל הדפים הם דפי משנה של `משתמש:בוט גאון הירדן/`.

| קובץ בריפו | דף באתר | מה יש בו | מתי נטען |
|---|---|---|---|
| `site/main.js` | הקובץ הראשי של הגאדג'ט | מי מריץ את הכלי, מחוון הגודל, טעינת כל השאר | תמיד |
| `site/core.js` | `Gadget page tool.core.js` | הבדיקה מול ויקיפדיה (בלי תצוגה) | בכל ערך |
| `site/card.js` | `Gadget page tool.card.js` | הכרטיסים והפעולות | כשצריך כרטיס |
| `site/messages.js` | `Gadget page tool.messages.js` | המלל של הכרטיסים | עם הכרטיס |
| `site/style.css` | `Gadget page tool.css` | העיצוב של הכרטיסים | עם הכרטיס |
| `site/details.js` | `Gadget page tool.details.js` | פאנל "פרטים" | בלחיצה על החץ |
| `site/preview.js` | `Gadget page tool.preview.js` | תצוגה מקדימה בריחוף | בריחוף על קישור |
| `site/update.js` | `Gadget page tool.update.js` | "מאז הייבוא" | בלחיצה על הפקד |
| `site/links.js` | `Gadget page tool.links.js` | חלון תיקון קישורים | בלחיצה, לקבוצת bot |
| `site/redirects.js` | `Gadget page tool.redirects.js` | הפניות מוויקיפדיה, ודף שאינו קיים | למשתמש מחובר |
| `site/הפניות.js` | `הפניות.js` | כפתור "הצג/הסתר", "פתיח", גאדג'ט הקישורים האדומים | תמיד |

**סדר הדבקה:** קודם כל הקבצים שנטענים לפי הצורך, ורק בסוף הקובץ הראשי ו־`הפניות.js`.

## בדיקות

```bash
npm install   # פעם אחת
npm test
```

הבדיקות מריצות את הקבצים עצמם בדפדפן מדומה, מול ויקי מדומה, ובודקות מה המשתמש רואה ומה נשלח לשרת. שום דבר לא נשלח לאתר האמיתי. הן רצות גם אוטומטית בגיטהאב בכל שינוי: ירוק - עובד, אדום - משהו נשבר.

הבדיקות לא מחליפות בדיקה קצרה באתר אחרי הדבקה, כי השרתים האמיתיים (המכלול, ויקיפדיה, שרת הייבוא) לא משתתפים בהן.

| תיקייה | מה נבדק |
|---|---|
| `tests/contract` | ההכרעה: 25 מצבים מול תוצאה צפויה |
| `tests/card` | הכרטיסים והפעולות: 251 תרחישים |
| `tests/update` | "מאז הייבוא" |
| `tests/links` | חלון תיקון הקישורים |

## החלטות שכדאי לזכור

- הכלי רץ רק בצפייה בערך (מרחב ראשי), לא בדף הראשי, לא בדף הבדלים, ולא בערכים שנכתבו או תורגמו במכלול.
- זיהוי הערך בוויקיפדיה: לפי מספר הגרסה בתבנית "מיון ויקיפדיה", אחר כך לפי פריט ויקינתונים, ורק אחר כך לפי השם.
- "לא נבדק" אינו "לא": כשבדיקה נכשלת, הכלי אומר זאת ולא מבצע פעולה אוטומטית.
- כללי השמות בין המכלול לוויקיפדיה: "רבי"/"הרב", ה"קדוש", "אישיות מהתנ"ך", א־ל. שדה `דף=` בתבנית שומר תמיד את השם בוויקיפדיה.
- שדות התבנית (דף, גרסה, פריט) נקראים מהדף עצמו, מ־`#wikiPageName`, `#wikiRevid` ו־`#qid` שהתבנית מציגה. רק כשאין אף אחד מהם, הכלי שולף את הוויקיטקסט.
- ערך שמוזג בוויקיפדיה (הכותרת שם הפכה להפניה): אין העברה. אם הערך המאחד קיים במכלול, מוצעת הפיכה להפניה אליו; אחרת בדיקה ידנית.
- פירושונים בשני האתרים: מחוון גודל ו"מאז הייבוא" כמו בערך רגיל.
- דף שהוא הפניה במכלול: אף פעם לא העברה או מחיקה, רק עדכון יעד ההפניה. כשהיא מובילה לאותו יעד כמו בוויקיפדיה, מוצג סימן ירוק.
- הפניות אל דף שהועבר מוצעות לעדכון רק אחרי העברה בלי הפניה. בהעברה עם הפניה הן הופכות לכפולות, וכלים אוטומטיים מטפלים בהן.
- הרשאות: העברה ומחיקה לפי הרשאות המשתמש. חלון תיקון הקישורים רק לקבוצת bot. כפתור ההבדלים רק למי שחבר גם ב־wikiupdate וגם ב־aspaklaryaEditor. הפניות שנמחקו בעבר רק ל־aspaklaryaEditor.

## ידוע ולא טופל

- בקשות ממפעילים נשלחות לדף מספר 18228, לפסקה 6 (העברה) ולפסקה 1 (מחיקה). אם סדר הפסקאות בדף הבקשות ישתנה, צריך לעדכן את המספרים ב־`site/card.js`.
- כפתור "הצג/הסתר" משתמש ב־`rvdifftotext`, שמדיה־ויקי סימנה כמיושן. אם יפסיק לעבוד, צריך לעבור ל־`action=compare`.
- בביטול שקט של בקשה (בעיקר ביציאה מהדף) שלד הטעינה נשאר. אין לזה השפעה מעשית.
