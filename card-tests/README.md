# סוויטת בדיקות הכרטיס והפעולות

סוויטה קבועה לשכבת הכרטיס והפעולות של Page tool. היא מריצה את שבעת קבצי הייצור **כפי שהם, בלי שום שינוי**, בתוך דפדפן מדומה עם ג'יי-קוורי אמיתי, ובודקת מה המשתמש רואה, אילו בקשות נשלחות ואילו כתיבות היו נשלחות.

הסוויטה משלימה את `contract-tests/`: סוויטת החוזה בודקת את מנוע ההכרעה, וזו בודקת את כל מה שקורה אחריו.

## התקנה והרצה

נדרש Node.js בגרסה 18 ומעלה. לא נדרש דפדפן.

```bash
cd card-tests
npm ci            # פעם אחת: jsdom 24.1.3 ו-jquery 3.7.1, נעולים בקובץ הנעילה
cd ..
node card-tests/run.js
```

| פקודה | מה היא עושה |
|---|---|
| `node card-tests/run.js` | הרצה מלאה מול תמונות הייחוס |
| `--scenario <מזהה>` | תרחיש אחד (אפשר לחזור על הדגל) |
| `--grep <טקסט>` | תרחישים שהמזהה או הכותרת שלהם מכילים את הטקסט |
| `--list` | רשימת התרחישים בלי הרצה |
| `--require-baseline` | כישלון אם קבצי הייצור שונים מהבסיס הנעול |
| `--tool <תיקייה>` | הרצה על עותק אחר של הכלי |
| `--compare <תיקייה>` | השוואת שתי גרסאות זו מול זו, בלי תמונות ייחוס |
| `--update-snapshots` | כתיבת תמונות ייחוס (ראו בהמשך) |
| `node card-tests/sensitivity.js` | מבחני רגישות (ראו בהמשך) |

## מבנה הבדיקה

**רמה א' — הכרעה מוזרקת.** הקובץ הראשי, הכרטיס, הפרטים, התצוגה המקדימה, ההודעות וקובץ העיצוב רצים באמת. הליבה האמיתית נטענת ומספקת את כל כלי הרשת והפענוח, אבל תוצאת ההכרעה מוזרקת מקטלוג (`fixtures/results.js`). כך אפשר לבדוק כל מצב כרטיס מול כל פרופיל הרשאות, בלי תלות בלוגיקת ההכרעה.

**רמה ב' — שרשרת מלאה.** גם הליבה רצה במלואה, על 25 תרחישי סוויטת החוזה (נקראים משם, לא מועתקים). בכל תרחיש, תוצאת הליבה שהתקבלה בתוך השרשרת חייבת להיות זהה לתמונת הייחוס של סוויטת החוזה: אותה תוצאה ואותן קריאות רשת. זה מוכיח שהרשת המדומה כאן היא אותה רשת, ושהחיבור לקובץ הראשי לא שינה דבר.

| קבוצה | תרחישים | מה נבדק |
|---|---|---|
| מטריצה: כרטיס העברה | 79 | וריאנטים של בדיקות לפני פעולה × 5 פרופילי הרשאות, לשינוי שם ולהפניה. אין פרופיל של משתמש לא רשום: הוא אינו יכול לערוך, ועריכה ובקשה פתוחות לכל משתמש רשום |
| מטריצה: מצבים | 26 | נמחק, הועבר למרחב אחר, פירושונים, כבר טופל, מעגל, שרשרת ארוכה, לא ידוע |
| מטריצה: נמצא ואזהרות | 10 | מחוון הגודל, גרסה שנמחקה, כשלי מקורות, מצב תואם עם אזהרה |
| מטריצה: כשל | 4 | כרטיס כשל עם שגיאת רשת ועם שגיאה כללית |
| אינטראקציה | 51 | פרטים, בורר הפניה, כל הפעולות, שגיאות העברה, תצוגה מקדימה, עץ המקשרים, הרשאות, טעינת משאבים, ניסיון חוזר |
| רמה ב: שרשרת מלאה | 25 | כל תרחישי החוזה, מהשער ועד פתיחת הפרטים |
| הפניות מוויקיפדיה | 25 | הפקד ליד מחוון הגודל, החלונית, עריכה בלחיצה, ייבוא בודד ומסומנים, אישור עיון, הרשאות, נמחקה בעבר (ראו `WIKI_REDIRECTS.md`) |
| דף שאינו קיים | 11 | כרטיס "נראה שהערך קיים בשם אחר", שקט בלי ממצא ובכשל, תיוג מנטרים, מסך העריכה |

בכל תרחיש נלכדת אחרי כל צעד **מסגרת**: מבנה הדף המנורמל (המכל, מחוון הגודל, קישור השפה, בועת התצוגה המקדימה וחלונית ההפניות מוויקיפדיה), בקשות הקריאה, בקשות הכתיבה (נלכדות ואינן נשלחות), טעינות סקריפטים וקובצי עיצוב, חלונות אישור והודעות מסוף.

## שלוש שכבות בדיקה

1. **בדיקות קבועות** אחרי כל צעד בכל תרחיש: אין שגיאה שלא נתפסה ואין דחייה ללא טיפול; אין בקשה בלי נתיב מוגדר; אין כתיבה בצעד שאינו פעולה; כרטיס ופאנל אחד לכל היותר; אין שורת אזהרה כפולה; אין טקסט חשוד (`undefined` וכדומה); היכולות שהכרטיס קיבל תואמות לכלל המיפוי מהרשאות; וכל פעולה גלויה מותרת לפי היכולות.
2. **בדיקות כוונה** בכל תרחיש, לפי ההתנהגות המתועדת במסמכי השלבים ובהערות הקוד. הפעולות הצפויות בכל תא של המטריצה מחושבות ממפרט שנוסח בנפרד מהקוד (`scenarios/matrix.js`), וכך גם כלל ההרשאות (`fixtures/profiles.js`).
3. **תמונות ייחוס** (`snapshots/`), קובץ לכל תרחיש, שתופסות כל שינוי אחר.

## עדכון תמונות ייחוס

כל הבדל בתמונת ייחוס נחשב שינוי התנהגות עד שהוא נבדק ומאושר. עדכון נעשה רק במפורש:

```bash
node card-tests/run.js --update-snapshots
```

תמונת ייחוס **לא נכתבת** לתרחיש שבדיקות הכוונה שלו נכשלו, כדי שהתנהגות שגויה לא תאושר רק משום שנשמרה. תמונות יתומות נמחקות רק בעדכון מלא שאינו מסונן.

## מבחני רגישות

```bash
node card-tests/sensitivity.js            # כל השבירות, כ-4 דקות
node card-tests/sensitivity.js --only <מזהה>
```

כל מבחן מעתיק את קבצי הייצור לתיקייה זמנית, שובר בה במכוון התנהגות מתועדת אחת, ומריץ עליה את כל הסוויטה. לכל שבירה מוגדרת רמת התפיסה הצפויה: בדיקת כוונה, תמונת ייחוס בלבד (לשינוי לגיטימי), או לא נתפס (מחוץ לגבולות הסוויטה). המבחן עובר רק אם כל שבירה נתפסה בדיוק ברמה הצפויה. המבחנים רצים רק על הבסיס הנעול.

## השוואת גרסאות

```bash
node card-tests/run.js --compare ../גרסה-אחרת
```

שתי הגרסאות מורצות על אותם תרחישים, והמסגרות שלהן מושוות זו לזו. שימושי לפני החלפת קוד באתר: כל הבדל בהתנהגות מוצג, בלי קשר לתמונות הייחוס.

## מה הסביבה מחליפה, ומה אינו נבדק

הסביבה מחליפה רק את מה שאין בדפדפן מדומה, וכל החלפה מתועדת בקוד:

- **בדיקת הנראות** של ג'יי-קוורי (`:visible`) מחזירה בדפדפן מדומה תמיד "מוסתר", כי אין פריסה. היא מוחלפת בבדיקת סגנון התצוגה המחושב של האלמנט ושל הוריו.
- **אישור העיון של האתר** (`ext.gadget.alert-script`) מדומה לפי התרחיש: מאשר, דוחה או לא נטען. בסביבה אין שם משתמש ומזהה דף אלא אם התרחיש מגדיר אותם, ולכן הזיהוי האוטומטי של ההפניות לא רץ בתרחישים הישנים.
- **קובץ העיצוב** נטען דרך תגית קישור. הסביבה מחילה את הקובץ האמיתי מהדיסק ומפעילה את אירוע הטעינה או הכשל.
- **הזמן** מדומה. השהיות, ניסיונות חוזרים ותשובות שרת רצים לפי שעון מדומה, בלי המתנה אמיתית.
- **הרשת ופעולות הכתיבה** מדומות מול ויקי קטן בזיכרון (`lib/wiki.js`), כך שקריאה אחרי פעולה רואה את תוצאתה.

מחוץ לגבולות הסוויטה: מראה ועיצוב (צבעים, מרווחים, פריסה בפועל), תצוגת המובייל (הסביבה מדמה את העיצוב הרגיל), הסמנטיקה המדויקת של ממשק מדיה־ויקי מול שרת אמיתי, וגרסת ג'יי-קוורי שרצה באתר בפועל. לכן בדיקה חיה קצרה באתר עדיין נדרשת לפני החלפת קוד.

## התנהגויות ידועות

תרחישים עם השדה `knownIssue` מתעדים התנהגות קיימת שאינה רצויה ולא תוקנה בשלב הזה. הם מופיעים בסיכום כל הרצה. תיקון עתידי ישנה את תמונת הייחוס שלהם במכוון.
