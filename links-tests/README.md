# סוויטת בדיקות לחלון תיקון הקישורים

טוענת את מודול החלון ואת קובץ המלל מתיקיית החבילה, בדפדפן מדומה (אותן גרסאות נעוצות כמו בסוויטת הכרטיס), עם רשת ושמירה מדומות.

הרצה: `npm ci` ואז `node run.js`. יוצאת בקוד כשל אם בדיקה נכשלה.

## מה נבדק
1. **פונקציות טהורות**: כל שורות טבלת הצורות מהמפרט בשני אופני ההחלפה; הערות, לא־ויקי, טקסט מעוצב מראש וקוד; תגית שסוגרת את עצמה; קישור בתוך כיתוב קובץ; סימני דולר; כלל ברירת המחדל; מפתחות למופעים זהים.
2. **זרימה מלאה**: טעינה בלי מעקב אחרי הפניות; קישור ויקיפדיה משדה התבנית; טקסט הדף לא מורץ כקוד; מעבר קדימה אחרי החלפה; המיקוד לא עובר לתיבת העריכה; התנגשות, טעינה מחדש ששומרת החלטות ושמירה מוצלחת; דף בלי קישור; שינוי ברירת המחדל; דף חסר; סיכום.
3. **תיקוני הסקירה**: דף שהפך להפניה מוצג כמצב מפורש ואינו נערך; כשל רשת, התנגשות ושגיאת הרשאה ואז דילוג נספרים כנכשלים; אישור לפני שמירה כשנשארו מופעים ממתינים; המספר האמיתי של הדפים שנשלפו.
4. **נוספו רק סוגריים**: ברירת המחדל היא תיקון הקישור בלבד.
