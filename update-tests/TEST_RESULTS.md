## הסוויטה `update-tests/run.js`
הורצה על החבילה הנוכחית (21 בספטמבר 2026, כולל סבב ההפניות): **30/30 עברו**. ברירת המחדל בסביבה המדומה היא משתמש שחבר ב־`wikiupdate` וב־`aspaklaryaEditor`, ויש שני תרחישי הרשאות מפורשים.

- PASS הפקד מוצג ליד מחוון הגודל, בלי קריאות ובלי טעינת קובץ לפני לחיצה
- PASS אין שינוי מאז הייבוא: אין פקד, אין קריאה ואין טעינה
- PASS אין פקד כששדה הגרסה חסר, אפס או לא מספרי
- PASS אין פקד כשידוע שגרסת הייבוא נמחקה
- PASS לחיצה ראשונה: קובץ אחד נטען, שתי שאילתות, החלונית בגוף הדף ולא בשורת המחוון
- PASS עדכון: הזמן והמשתמש מהיסטוריית המכלול, והשינויים מוויקיפדיה
- PASS ייבוא בלי עדכון
- PASS יש עדכונים ממוספרים אך אין התאמה: אין מידע גלוי + אי־התאמה
- PASS נמצא עדכון תואם ישן יותר: זמנו מוצג, והעדכון האחרון השונה נשאר כממצא
- PASS אין תקציר מתאים בהיסטוריה: "אין מידע", בלי כפתור ניסיון חוזר
- PASS דפדוף בהיסטוריה המקומית: אובייקט ההמשך ממוזג כולו
- PASS כשל בהיסטוריה המקומית אינו מבטל את נתוני ויקיפדיה; ניסיון חוזר שולף רק אותה
- PASS כשל בוויקיפדיה אינו מבטל את נתוני המכלול; ניסיון חוזר
- PASS כשל קבוע אינו מציע ניסיון חוזר
- PASS גרסת ייבוא שאינה בהיסטוריית הדף: ממצא קבוע, בלי ניסיון חוזר
- PASS גרסה שאינה קיימת כלל בוויקיפדיה: אותו ממצא קבוע
- PASS קוד badid_rvendid: ממצא קבוע ולא שגיאת רשת
- PASS דפדוף בגרסאות ויקיפדיה: אובייקט ההמשך ממוזג, והספירה נכונה
- PASS טבלת ההבדלים: רק בלחיצה, מגרסת הייבוא לגרסה שנספרה, בלי כפיית כיוון
- PASS מצב direct: גם הגרסאות וגם ההשוואה נשלחות ישירות לוויקיפדיה
- PASS ויקיפדיה נערכה אחרי טעינת הדף: ההבדלים מתארים את אותו טווח שנספר
- PASS כשהספירה נכשלה, ההבדלים עדיין זמינים מול הגרסה שהכלי ראה
- PASS כשל בטעינת ההבדלים: הודעה, וניסיון חוזר מצליח
- PASS כשל קבוע בהבדלים: הודעה בלי ניסיון חוזר
- PASS סגירה ופתיחה בלי שאילתות נוספות; כפתור הסגירה מעדכן את הפקד
- PASS כשל בטעינת קובץ העדכון: הודעה בפקד, ולחיצה נוספת מנסה שוב
- PASS ניסוחי זמן וספירה
- PASS אין שגיאות לא מטופלות בכל ההרצות
- PASS ללא קבוצות הרשאה: הנתונים מוצגים, אין כפתור הבדלים ואין compare
- PASS חברות בקבוצה אחת בלבד אינה מציגה כפתור הבדלים
