# בדיקות דפדפן — המועמד המשולב

הורץ מחדש ב־Chromium אמיתי עם jQuery אמיתי לאחר הוספת הגבלת הקבוצות, ושוב על החבילה הנוכחית (21 בספטמבר 2026, כולל סבב ההפניות). בקובץ הבדיקה כתוב נתיב קבוע לכרומיום; ההרצה האחרונה נעשתה מעותק זמני שמצביע על הכרומיום שבסביבה, בלי לשנות את הקובץ.

- PASS התאמת גרסה + mismatch + endpoints ברירת מחדל + diff עובד
- PASS עדכון ממוספר ללא התאמה מציג אין מידע + mismatch
- PASS ייבוא משמש fallback רק כשאין עדכון ממוספר
- PASS מצב direct משתמש ב־API של ויקיפדיה לשתי הבקשות
- PASS retry מוצג רק לכשל רגעי ומצליח
- PASS כשל קבוע אינו מציע retry
- PASS כשל קבוע מציג את הודעת הליבה עצמה
- PASS כשל רגעי ב־diff שומר listener ומאפשר retry
- PASS כשל קבוע ב־diff מאפס תווית לפני הסתרה ומציג הודעת ליבה
- PASS `badid_rvendid` מוצג כממצא קבוע ספציפי
- PASS pagination מלא מעל 500 עם אובייקט continuation מלא
- PASS ה־diff מסתיים בגרסה שנמדדה ולא בגרסה הישנה מהטעינה
- PASS מסך צר: החלונית נפרדת ואינה נדחסת ליד הטריגר
- PASS אין שינוי: אין טריגר ואין קריאות
- PASS ללא קבוצות הרשאה: הנתונים מוצגים בלי כפתור ובלי compare
- PASS קבוצה אחת בלבד אינה מספיקה להצגת ההבדלים
