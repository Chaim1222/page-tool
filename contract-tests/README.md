# סוויטת חוזה — Page tool

הסוויטה בודקת את מנוע ההכרעה. על הבסיס הקפוא היא לוכדת את הקובץ הראשי; לאחר חילוץ הליבה היא קוראת ישירות ל־`Gadget page tool.core.js`.

## מה נלכד

לכל תרחיש נשמרים שני דברים בלבד:

1. תוצאת ההכרעה בנקודת הסיום: הצלחה, כשל או ביטול שקט.
2. קריאות הרשת שבוצעו עד אותה נקודה.

קריאות שמתחילות בשכבת הכרטיס אינן נכללות: הקלטת הרשת נעצרת ברגע הלכידה.

במצב שבו `localStateMatches` מדכא את הכרטיס, התרחיש נשמר כהצלחה עם `delivery: "suppressed"`; אובייקט התוצאה עצמו אינו משתנה לצורך הבדיקה.

## נרמול

- מפתחות אובייקטים מסודרים באופן דטרמיניסטי.
- שגיאות נשמרות כ־`kind`, `transient`, `silent` בלבד.
- `errorMessage` אינו נשמר.
- קריאות רשת מקובצות לפי שלב. בתוך קבוצה הן ממוינות, ולכן סדר שתי בקשות מקביליות אינו משמעותי; סדר הקבוצות כן משמעותי.
- אין השמטות שקטות של שדות תוצאה.

## הרצה

מהתיקייה הראשית של הארכיון:

```bash
node contract-tests/run.js
```

מול גרסה אחרת בתיקייה אחרת:

```bash
node contract-tests/run.js --tool . --compare ../other-version
```

אפשר להעביר גם נתיב ישיר לקובץ הראשי או ל־`Gadget page tool.core.js`. כאשר מעבירים תיקייה שיש בה core, הוא נבחר אוטומטית לבדיקה ישירה.

המריץ אוסף כשלים מכל התרחישים ומציג אותם יחד, במקום לעצור בכשל הראשון.

הרצת תרחיש יחיד:

```bash
node contract-tests/run.js --scenario log-floor-rejected
```

## עדכון תמונות ייחוס

עדכון הוא פעולה מפורשת בלבד:

```bash
node contract-tests/run.js --update-snapshots
```

אין להריץ את הפקודה כחלק מהרצת CI רגילה. כל הפרש נחשב שינוי התנהגות עד שאושר במפורש.

## נקודות הלכידה

בגרסה הישנה ה־harness מזריק hooks **רק לעותק שבזיכרון** בזמן הבדיקה:

- `renderResultWhenReady` — הצלחה שנמסרת לתצוגה.
- ענף state-match שמדכא כרטיס — הצלחה מדוכאת.
- `showFailureCardWhenReady` — כשל גלוי.
- `catch` של שגיאה `silent` — ביטול שקט.

מותרת לכל היותר נקודת סיום אחת בכל תרחיש. בגרסה עם core אין צורך ב־hooks: אותה מעטפת נבנית ישירות מה־Promise שמחזירה `core.run`.

## התרחישים

הסוויטה מכסה:

- סדר מקורות: גרסה, גרסה שנמחקה, fallback לפריט, fallback לכותרת.
- baseline: זהות, שינוי שם, `already_synced`, פירושונים שהועבר.
- שרשרת: הפניה, עומק, מעגל.
- יומן: העברה, מחיקה, מרחב אחר, ראיה ישנה, כשל גבול זמן.
- state match: יעד ופסקה, פסקאות שונות, פירושונים, אזהרה שגוברת על התאמה.
- דף מקומי: דף חסר ובדיקת יעד משנית שלא הושלמה.
- שגיאות: retry רגעי, כשל קבוע וביטול שקט.

הרשאות אינן חלק מחוזה ההכרעה ונשארות בסוויטת הכרטיס/פעולות.
